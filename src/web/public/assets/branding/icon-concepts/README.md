Every source image is square (`1254 × 1254`), uses an alpha channel, and remains
unwired from the product until a direction is selected.

## Shared generation brief

- Use case: `logo-brand`.
- Product: Issopen, a self-hosted issue tracker used by humans and AI agents.
- Style: minimal, vector-friendly flat mark with crisp geometry and a strong
  silhouette.
- Format: isolated square icon on a genuinely transparent background.
- Constraints: icon only, no text, maximum two colors, no mockup and no
  watermark.

Each filename records the concept-specific prompt direction.
