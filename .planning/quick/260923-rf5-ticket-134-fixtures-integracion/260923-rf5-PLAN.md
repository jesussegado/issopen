# Ticket 134 — Fixtures compartidos de integración

## Objetivo

Eliminar setup copiado en las cuatro suites mayores manteniendo explícitos los
actores, workspaces, permisos y contratos que cada escenario demuestra.

## Trabajo

1. Encapsular el ciclo contenedor/migración/reset/cierre de PostgreSQL sin
   compartir estado entre suites.
2. Extraer runtime HTTP, inicio de sesión y builder de Member con grants
   explícitos.
3. Extraer drivers del transporte MCP y de la instalación OAuth Chrome.
4. Migrar incrementalmente HTTP, MCP, extensión y tracker; ejecutar las cuatro
   juntas para demostrar aislamiento y paralelismo.
5. Hacer ejecutable la frontera y retirar ruido stderr de fallos Git esperados.
6. Completar gates, publicar una imagen inmutable y verificar producción.

## Riesgos y rollback

- Riesgo: fixture con estado implícito o defaults que oculten el contrato.
- Control: listas de tablas, identidades y grants siguen declarados en suites.
- Rollback: revertir el commit de tests; no existe migración ni cambio runtime.
