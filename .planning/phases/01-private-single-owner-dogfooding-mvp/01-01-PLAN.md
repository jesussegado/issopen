| Threat | Severity | Mitigation |
| --- | --- | --- |
| Anonymous data access | high | Protected-by-default API middleware and negative HTTP tests |
| Concurrent second-owner bootstrap | high | Singleton database constraint plus transaction/advisory lock and concurrency test |
| Credentials in logs/Git | high | Prompt/process env input, redaction, ignored `.env`, response/log scans |
| Session theft/CSRF | high | HttpOnly SameSite cookie, trusted origins, Secure in HTTPS mode, recovery revokes sessions |
