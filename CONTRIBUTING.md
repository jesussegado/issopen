# Contributing to Issopen

Thank you for helping improve Issopen. Bug reports, product feedback,
documentation and code contributions are welcome.

## Before you start

- Search the existing issues before opening a new one.
- Discuss substantial changes in an issue before investing in an implementation.
- Never include credentials, personal data, production exports or other secrets.
- Keep each pull request focused on one change and explain how it was verified.

## Submit a pull request

1. Fork `jesussegado/issopen` and create a branch from `main`.
2. Follow the repository instructions in `AGENTS.md`.
3. Add or update tests and documentation when the change requires them.
4. Run the relevant checks and describe the results in the pull request.
5. Complete the contribution-terms checkbox in the pull request template.

Maintainers may ask for changes or decline a contribution. Opening a pull
request does not guarantee that it will be merged.

## Reporting security issues

Do not publish a suspected vulnerability or sensitive evidence in a public
issue. Contact `serviciosegado@gmail.com` with a minimal description so the
maintainers can coordinate a fix and safe disclosure.
